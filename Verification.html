Historical speech-service observations

  • Whisper buffered, partial, and SSE endpoints returned real transcripts using faster-whisper 1.2.1 with PyAV 18.1.0. A fresh PyAV 19 install failed decoding; the optional dependency now constrains PyAV below 19 and CI exercises a real WAV decoder without model weights.
  • Kokoro 0.9.4 with Torch 2.14.1+cpu produced valid mono WAV and SSE audio. Busy requests returned retryable HTTP 503 while health stayed available.
  • CPU synthesis was slower than the resulting speech duration. Warm models and measure the selected presentation hardware.

Synthesis and channel ownership

Twenty-four real HTTP fixture cases cover request retirement during model loading, first inference, and later steps for buffered WAV, streamed WAV, and PCM SSE. They verify one receive consumer, no later native step, safe active-work drain, and recovery on the same cached runtime. Eight pre-header error cases preserve JSON status responses. Built-in channel tests also cover atomic idle/cursor admission, reset cancellation, duplicate-report identity, and explicit recovery when bounded event history is lost; legacy queuing and custom adapter memory retain their contracts.

Transcription ownership at 5d0c7a4

Real multipart uploads and FFmpeg with a deliberately held local provider verified disconnect recovery for buffered, partial, and SSE transcription. All three closed the provider connection within a 650 ms observation; a fresh request completed on the same sole pool worker before manual provider release, with no retained capture directory or borrowed token. Cancellation prevents later decoder/native steps, fallback, and cache mutation; active native work finishes before serialized cleanup. This does not establish provider-side compute cancellation.

A separate offline repeat used actual cached Whisper tiny.en CPU/int8 weights through all three endpoints: HTTP 200, nonempty transcripts, SSE done without error, and zero active model leases afterward.
