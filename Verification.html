Observed runtime verification

Hackathon refactor preview · 22 October 2026. Work is being reviewed on codex/hackathon-refactor, based on alpha. These changes are not yet merged into alpha or the release branch. Setup and rehearsal guide · Progress and verification evidence · Review PR #24.

These are local observations from 22 October 2026. Exact versions, model revisions, timings, and later check totals are recorded in the repository verification record.

Real browser voice path

Chromium captured an espeak-ng WAV through its fake microphone using native MediaRecorder and VAD. Korina ran actual tiny.en Whisper CPU/int8 transcription, sent the transcript to a deterministic local response fixture, synthesized the reply with actual Kokoro af_heart on CPU, and scheduled nonzero PCM through native WebAudio. Playback reached its ended event; stopping live mode released capture. There were no page or console errors.

The small Whisper model made recognition errors. This smoke proves the runtime path, not transcription quality or presentation latency. The integration run also exposed duplicate current-turn delivery to the LLM; the refactor corrects the history contract and adds executable regressions.

The follow-up full-final path discarded redundant partial work instead of waiting for it to drain. One partial request completed and the next was aborted by the browser. A client abort does not prove backend inference was cancelled. All three timings are single observations, not a controlled benchmark. The latest run exercised the bounded recorder, strict SSE parser, shared HTTP transport, and leased Whisper model; it raised no page/console errors and Stop released the microphone.

Actual speech services

  • Whisper buffered, partial, and SSE endpoints returned real transcripts using faster-whisper 1.2.1 with PyAV 18.1.0. A fresh PyAV 19 install failed decoding; the optional dependency now constrains PyAV below 19 and CI exercises a real WAV decoder without model weights.
  • Kokoro 0.9.4 with Torch 2.14.1+cpu produced valid mono WAV and SSE audio. Busy requests returned retryable HTTP 503 while health stayed available.
  • CPU synthesis was slower than the resulting speech duration. Warm models and measure the selected presentation hardware.

Agent and permission integration

Seven scenarios passed through actual Chromium modules, the real backend/agent worker, and a local deterministic model fixture: sanitized prompt delivery, exactly one next-response injection, permission answer/follow-up, reset while a model call was held, fresh-session recovery, and delayed-chat suppression. Reset took 72 milliseconds; agent model HTTP concurrency stayed at one. Speech in this check was a short silent PCM fixture, with no external model inference or tool execution.

Real response and agent inference

A separate run at immutable fb996a1 used actual pinned SmolLM2-135M-Instruct inference for both response and agent roles, with real Whisper, Kokoro, and native browser capture/playback. The local CPU wrapper used the unchanged Korina messages and model chat template, cached safetensors, no remote code, and no paid inference service.

Actual-model repeat at d14a371

The current immutable checkpoint completed the same real CPU model pipeline in 27.537 seconds. Whisper handled 8.82 seconds of audio in 4.669 seconds; response inference took 5.491 seconds. Kokoro produced 61,200 samples at 24 kHz and the 2.55-second native buffer reached its ended event. Agent inference took 20.278 seconds, and its report appeared exactly once in a real follow-up response. All six readiness requests passed; no page/console errors; Stop released capture; disposable services stopped.

The same known recognition error and mostly echoed model answers remain. This is another single observation, not a controlled speed comparison, a physical-device test, or presentation-quality evidence. Earlier output files are preserved.

Automated checkpoint

Immutable d14a371 passed 932 Python tests with 93% coverage, 313 executable Node tests, 57 real Chromium tests, expanded lint/type checks, isolated source/wheel builds, and separate installed-wheel checks of all 29 matching assets. Clean Python 3.10, 3.11, and 3.13 each passed 931 tests plus the optional decoder skip; Python 3.12 exercised it. See testing and issue #23 for later work. Hosted Actions jobs did not start because of account billing/spending limits.

Connected request regressions prove stale agent/ACK I/O closes and the same worker accepts fresh work; they do not assert remote model computation stops. Agent off/on and Kokoro native cleanup have dedicated executable and Chromium regressions.

Physical microphone/headset behavior, audible speakers, human interruption, useful presentation response/agent models, GPU execution, and event-specific Meta requirements still need rehearsal. Use the demo checklist. Pages source is maintained on gh-pages; live hosting is not configured.
