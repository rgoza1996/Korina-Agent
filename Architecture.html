Architecture Overview

Full source-grounded report: docs/refactor/architecture-report.md on beta.

Product Split

Korina Converse — the local-first, voice-first design chat channel. It owns the human-facing loop: microphone input, VAD/endpointing, STT, response-LLM calls, TTS playback, barge-in, agent interrupts, and permission prompts. Converse is intended to be a channel that can host multiple agents: Korina Agent, Hermes Agent, OpenClaw, or another compatible local/OpenAI-style agent.

Korina Agent — the local-first agent built for that channel. Today it receives transcript deliveries, maintains compact state, emits background reports/events, and asks Converse to inject context or speak important/critical interrupts.

Runtime Shape

Korina Converse ↔ Korina Agent ↔ external agents all share one local FastAPI backend on port 8001.

Current Implementation Highlights

  • Python backend package under korina/ with 10 route modules and 9 service modules.
  • Browser frontend split into native ES modules under Korina/js/ (17 modules, 2333 lines).
  • Backend-owned provider registry exposed by GET /api/capabilities.
  • Model catalog/capability helpers for endpoint-loaded models, local GGUFs, LM Studio catalogs, and mmproj sidecars.
  • Converse channel layer under korina/converse/ — ConverseChannel Protocol, thread-safe registry, default KorinaConverseChannel adapter bridging to the in-process agent gateway (Phase 5 Commit 1, shipped).
  • Agent gateway under korina/agents/ — AgentAdapter Protocol, agent_gateway() singleton, KorinaAgentAdapter default implementation.
  • CI-safe pytest suite (200+ tests across unit/API/static/converse layers) plus separate live regression smoke script.
  • GitHub Actions workflow running pytest on Python 3.10 / 3.11 / 3.12.

Main Follow-up Themes

1. Formal Agent Protocol for Third-Party Agents

Phase 5 Commit 1 ships the in-process adapter protocol (ConverseChannel). The next phase is the public/converse split: pip install korina-converse with optional [hermes] and [openclaw] extras, so third-party agents can ship as separate packages and wire into Converse through the public seam.

2. Korina Agent Execution/runtime Layer Beyond State Reports

Korina Agent currently emits state reports/events. Add: tool/action adapters, durable task state, side-effect permission gates, project trust enforcement, transport abstraction.

3. Composite Readiness Across Backend, LLM, STT, TTS, ACK

One clear readiness contract covering backend, selected response LLM, STT backend/degraded fallback, TTS endpoint, ACK cache state, and served frontend asset freshness.

4. Portable Install/config Paths

Move local runtime paths, model roots, and service binary assumptions behind config/env settings. Document a generic install contract.

5. Probe-backed Model Capabilities

Turn model capability metadata into a probe-backed layer recording model source, sidecar/mmproj presence, audio-input support, last probe status/error.

6. Optional Live/Self-hosted Regression Tier

Add an opt-in live regression job/script for a local/self-hosted runner with real services and model weights.

7. Public-doc vs Internal-runbook Cleanup

Zoomable code-explorer mindmap. See Issue #10.
