Issue Details

#3 — Formalize Korina Converse agent protocol high ARCH-1

Define a versioned external-agent contract for transcript delivery, event stream format, injection vs. interrupt semantics, permission-request/answer flow, priorities, sanitization, and attached-agent capability discovery. Goal: make Korina Converse a reusable local-first design chat channel for Korina Agent, Hermes Agent, OpenClaw, or another compatible agent.

#4 — Finish Korina Agent local-first execution runtime high ARCH-2

Korina Agent currently emits state reports/events. Add: tool/action adapters, durable task state, side-effect permission gates, project trust enforcement, transport abstraction, and a clean separation between reporting to Converse and acting on the world.

#5 — Add composite readiness for local voice stack medium ARCH-3

Expose one clear readiness contract covering backend, selected response LLM, STT backend/degraded fallback, TTS endpoint, ACK cache state, and served frontend asset freshness. Removes ambiguity where the FastAPI backend is healthy but the selected local LLM service is stopped or still loading.

#6 — Make deployment paths, model roots, and local binaries portable medium ARCH-4

Move local runtime paths, model roots, and service binary assumptions behind config/env settings. Document a generic install contract and keep private host paths/specs out of public-facing docs.

#7 — Replace static model capability assumptions with probe-backed metadata low ARCH-5

Turn model capability metadata into a probe-backed layer that records model source, sidecar/mmproj presence, audio-input support, last probe status/error, and suggested fallback.

#8 — Add optional live/self-hosted regression tier low ARCH-6

Keep GitHub Actions lightweight, but add an opt-in live regression job/script for a local/self-hosted runner with real services and model weights. Publish concise readiness + smoke output without making normal CI depend on local services.

#9 — Audit public docs for environment-specific/private details low ARCH-7

README and the current architecture report are scrubbed, but historical refactor plans intentionally contain environment-specific operational notes. Decide which docs are public-facing vs internal runbooks, then scrub or clearly mark internal-only docs.
