Korina Converse

See the version 1 agent and Python channel contract, including browser routing boundaries.

The local-first, voice-first design chat channel. It owns the human-facing loop: microphone capture, VAD/endpointing, STT, response-LLM calls, TTS playback, barge-in, interrupts, and permission prompts. Converse is designed to be a channel that hosts any compatible agent.

Runtime choice: Whisper and Kokoro can run locally, while response and agent models use their configured endpoints. A remote endpoint receives the transcript and context Korina supplies; the focused Meta rehearsal explicitly used Meta Model API. Korina does not automatically choose a cloud response provider when a local model fails to fit.

Last response usage shows provider-reported input, output, reasoning and cached-input tokens separately from speech/history. Labels describe the original completed request. Zero remains zero; missing counts remain unavailable. Clear resets the panel and playback Stop retains completed counts. Usage contract.

Core Features

Live VAD

Browser-side adaptive energy voice activity detection with configurable endpointing thresholds: 3200ms silence for reading/dictation, 950ms for conversation mode.

Partial Transcription

Complete rolling windows (~1.8s each) provide feedback through a bounded queue. Overflow or a failed window falls back to the untouched complete recording.

Response LLM

The browser calls /api/chat; the backend forwards supplied context to the selected llama.cpp, LM Studio, Ollama, Meta, or generic OpenAI-compatible endpoint.

Kokoro TTS

Kokoro-compatible PCM SSE or buffered WAV playback, with selectable voices. Optional acknowledgement clips are cached per voice and generated when enabled.

⏸️ Barge-in & Interrupts

Speak during playback to interrupt. Agent interrupts use a configurable cooldown (default 3000ms padding) to prevent recursive interruption.

Permission UX

Permission requests from the agent are spoken by Converse and answered through the agent permission endpoint. Converse is always the human-facing permission surface.

Full-final capture and request ownership

In full-utterance final mode, pending endpoint silence holds new queued partial dispatches until speech resumes. Already admitted partial feedback can finish; resumed speech makes held windows eligible immediately. At the endpoint, the complete main recording supplies the final transcript. Chunks mode still drains its complete windows, and Stop retains its epoch, abort, and microphone-release behavior. This follow-up at 10a844a has no measured latency-saving claim.

Whisper rechecks request ownership after waiting for model/cache and inference locks, including before advancing a lazy native segment. A retired waiter starts no new native step. Work already inside model loading or inference still drains before serialized close and model-lease release; cancellation does not forcibly interrupt native computation. See the transcription and speech boundaries.

Python Converse channel interface

korina.converse exposes an independent Python interface for registered channel implementations. The browser voice loop continues to use /api/chat, transcription, TTS, and agent HTTP routes. Selecting a Python channel does not reroute that voice loop, and there is no public HTTP send/stream endpoint for this interface.

ConverseChannel interface

An abstract base class. Registered objects must be ConverseChannel instances with a channel name. Implement async send() and cancel(), plus stream() returning an async iterator. The default async health() can be overridden.

Thread-safe Registry

register_converse_channel(), unregister_converse_channel(), get_converse_channel(), set_active_converse_channel(), list_channels(), get_active_channel_name(). The active channel is process-global; reset_for_testing() clears it.

KorinaConverseChannel (default)

Captures the current agent_gateway() adapter, flattens non-assistant transcript text into one UserTurn, submits once, and polls fresh completion events after its admission cursor. Built-in admission requires an idle worker; an old last_report cannot complete a new send. Event-retention gaps and uncertain completion require explicit recovery.

Adapter author path and selection

Register a working ConverseChannel implementation at startup. The existing browser Channel picker saves a registered selection before publishing it; a failed save preserves the previous selection. Python callers can select in memory or provide a persistence callback. External integrations need their own implementation; Hermes remains an opt-in stub.
