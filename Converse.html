Korina Converse

The local-first, voice-first design chat channel. It owns the human-facing loop: microphone capture, VAD/endpointing, STT, response-LLM calls, TTS playback, barge-in, interrupts, and permission prompts. Converse is designed to be a channel that hosts any compatible agent.

Design principle: Korina is local-first — it is designed to keep your voice data and inference on your own hardware. However, it can fall back to cloud providers when your local hardware cannot fit the selected model. For example, running Qwen3-27B at Q8 (requires ~32GB VRAM) or GPT-OSS-120B at MXFP4 (requires ~64GB VRAM) is not realistic on typical consumer hardware.

Minimum System Requirements (Korina Converse)

Estimates based on faster-whisper base + Qwen3.5-0.8B as the lightweight STT + LLM baseline.

Minimalbasic functionality — 4 GB 2 GB CPU inference. whisper base (~74M) + Qwen3.5-0.8B Q8 (~1GB). Slow but functional. STT may hit CPU bottlenecks on older CPUs.

Goodgood experience 6–8 GB 16 GB 10 GB GPU-heavy. whisper base + Qwen3.5-3B Q8 (~3.2GB) or medium whisper model. Smooth multi-turn conversation with sub-3s perceived latency on modern GPUs (e.g. RTX 3060, RX 6600 XT).

STT models: faster-whisper base.en (~74M params, ~150MB INT8) is the minimum. Larger models (medium.en ~418M, large-v3 ~1.5B) improve accuracy at the cost of VRAM/speed.

LLM models: Qwen3.5-0.8B Q8 (~1GB) is the minimum viable for basic conversational quality. Qwen3.5-3B Q8 (~3.2GB) is the practical floor for decent response quality. Larger models (7B, 13B+) dramatically improve output quality but require corresponding VRAM headroom.

Kokoro TTS: TTS runs on CPU (omnivoice is lightweight, ~100MB RAM). No discrete GPU needed for TTS.

Core Features

🎤 Live VAD

Browser-side adaptive energy voice activity detection with configurable endpointing thresholds: 3200ms silence for reading/dictation, 950ms for conversation mode.

📝 Partial Transcription

Rolling partial transcription windows (~1.8s each) are queued rather than dropped, so slower STT inference catches up gracefully without losing audio.

💬 Response LLM

Browser sends transcript to the configured OpenAI-compatible response LLM endpoint. Provider-agnostic: llama.cpp, LM Studio, Ollama, or any custom endpoint.

🔊 Kokoro TTS

Kokoro/OpenAI-compatible TTS with Web Audio SSE streaming. Voices selectable in the UI. Acknowledgement phrases generated and cached per voice on startup.

⏸️ Barge-in & Interrupts

Speak during playback to interrupt. Agent interrupts use a configurable cooldown (default 3000ms padding) to prevent recursive interruption.

🔑 Permission UX

Permission requests from the agent are spoken by Converse and answered through the agent permission endpoint. Converse is always the human-facing permission surface.
