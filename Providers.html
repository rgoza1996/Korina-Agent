Provider Architecture

Provider metadata is backend-owned in korina/util/presets.py and exposed by GET /api/capabilities. The frontend reads from this registry — no JS file may hardcode provider rules.

Capability Contract

The full contract is documented in docs/capabilities.md. Key invariant: editable base URL iff editable_base_url: true.

Local Provider Lifecycle

When a manageable: true provider is selected, POST /api/llm/provider/activate starts/stops the local server. The activation response includes started and stopped lists so the UI can show what changed.

Adding a New Provider

  1. Add an entry to PROVIDER_CAPABILITIES in korina/util/presets.py.
  2. Add start_*/stop_* branches in korina/services/provider_manager.py if the provider is local.
  3. Run pytest and python3 tests/regression_smoke.py.
  4. Commit on beta.
