Testing & CI

Korina has a two-tier test strategy: CI-safe pytest for every PR, and a live roggoz regression smoke for end-to-end validation.

Test Pyramid

🟢 Live Regression (38 tests)

tests/regression_smoke.py — runs against the live service on roggoz. Covers provider activation, chat round-trip, STT, TTS, and the full /api/capabilities contract. Requires local services and model weights.

🔵 Static / Frontend (6 tests)

tests/frontend/test_static_frontend.py — module shape, fragile UI markers, adaptive barge-in thresholds, no-refresh-on-focus regression. Runs in CI.

🟣 API / TestClient (15 tests)

tests/api/ — FastAPI TestClient tests for config/capabilities/models/provider activation/validation. No live server required.

🟠 Unit Tests (22 tests)

tests/unit/ — config migration, model catalog, provider manager, audio probe, response formatting, labels, agent priority/sanitization. Run in CI.

CI Pipeline

GitHub Actions workflow (.github/workflows/test.yml) runs pytest -q on Python 3.10, 3.11, and 3.12. CI intentionally does not require llama.cpp, LM Studio, Kokoro, Whisper weights, GGUF files, or systemd.

Running Tests

# CI-safe pytest (from source checkout)
cd /home/roggoz/Korina-Agent
python3 -m venv /tmp/korina-test-venv
/tmp/korina-test-venv/bin/python -m pip install -e '.[test]'
/tmp/korina-test-venv/bin/python -m pytest -q

# Live roggoz regression (requires running service)
./Korina/install-services.sh
systemctl --user restart korina-voice-lab.service
python3 tests/regression_smoke.py --base http://127.0.0.1:8001 --no-chat --no-transcribe

What CI Does NOT Cover

Live model servers, local LLM provider activation, real Whisper inference, and Kokoro TTS playback. These are covered by the live smoke script, which runs on roggoz against the actual service.
