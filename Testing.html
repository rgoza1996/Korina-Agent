Testing & CI

Korina has 101 pytest tests across four layers: - Unit tests: backend module isolation - API/TestClient: FastAPI route contracts and response schemas - Static/frontend smoke: module shape, no-refresh-on-focus regression - Live regression: 49 release-gate smoke checks against a running backend CI runs on GitHub Actions across Python 3.10/3.11/3.12. The pytest suite avoids live model servers so CI is fast and deterministic. Current release gate: 101 pytest tests passing and 49 live smoke checks passing. Live regression (regression_smoke.py) is a separate script that exercises the running service. The default release gate uses --no-chat --no-transcribe so it validates frontend/API contracts without requiring local model availability; full chat/transcription smoke can be run when those services are up.
