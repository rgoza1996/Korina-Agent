Testing & CI

Korina has 81 pytest tests across four layers: - Unit tests: backend module isolation - API/TestClient: FastAPI route contracts and response schemas - Static/frontend smoke: module shape, no-refresh-on-focus regression - Live regression: full service smoke against running backend CI runs on GitHub Actions across Python 3.10/3.11/3.12. The pytest suite avoids live model servers so CI is fast and deterministic. Live regression (regression_smoke.py) is a separate script that exercises provider activation, chat, and transcription endpoints against a running service.
