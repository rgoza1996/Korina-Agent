Testing and CI

New: actual CPU speech and browser pipeline evidence, with exact boundaries and remaining rehearsal.

Hackathon refactor preview · 22 October 2026. Work is being reviewed on codex/hackathon-refactor, based on alpha. These changes are not yet merged into alpha or the release branch. Setup and rehearsal guide · Progress and verification evidence · Review PR #24.

Automated checks validate contracts without requiring model weights or running provider servers. Live smoke and hardware rehearsal are separate and must be recorded separately.

Local checks

python -m pip install -e '.[dev]'
python -m pytest -q
ruff check korina
mypy --ignore-missing-imports korina
npm ci --ignore-scripts
npm run lint
npm test
python -m build

The Python suite covers units, API behavior, static frontend contracts, Converse adapters, input limits, background concurrency, and STT fallbacks. Executable Node tests cover browser-independent frontend behavior. ESLint checks native ES modules for undefined imports and variables.

CI contract in the preview

  • Python tests and coverage artifacts across Python 3.10, 3.11, 3.12, and 3.13 on Ubuntu 24.04.
  • Python correctness lint, a baseline mypy check, and source/wheel builds, including an installed-asset check.
  • Node 22 frontend lint and executable JavaScript tests.

Read-only HTTP smoke

python scripts/check_stack.py --base http://127.0.0.1:8001
python scripts/check_stack.py --base http://127.0.0.1:8001 --allow-degraded

This reads the UI, stylesheet, JavaScript entrypoint, capabilities, health, and readiness. It does not reset sessions, change configuration, switch providers, or send prompts/audio. Exit 0 means its checks passed. --allow-degraded accepts a 503 readiness result from unavailable models while still checking the app/assets layer; it is not a successful voice rehearsal.

The manually dispatched Live voice-stack smoke workflow runs on a self-hosted runner labelled korina-demo and uploads a JSON report. The runner must be configured where it can reach the selected demo stack; ordinary CI does not require real model services.

Legacy regression and real rehearsal

The legacy suite mutates state. tests/regression_smoke.py performs session reset, ACK rebuild, provider activation, and temporary config writes even with --no-chat --no-transcribe. Use only a disposable or deliberately selected local stack. It is not the routine read-only gate.

The hackathon rehearsal checklist adds microphone permissions, actual speech playback, interruption, session reset, and provider failure recovery. Passing mocked or static checks does not establish those hardware results.

Platform and dependency scope

The backend/UI can be tested without optional speech engines. Install .[whisper] for faster-whisper and .[tts] for the local Kokoro server. FFmpeg is a system dependency for audio conversion. systemd service installation and local provider supervision are Linux specific.
