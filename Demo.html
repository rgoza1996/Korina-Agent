Verification, source and limits

One native screen-and-tab-audio capture produced the original video. The MP4 and WebM preserve its video timestamps and actual audio; no earlier speech buffers, guessed alignment, speed-up or removed waiting were added. Both formats passed native audible-output and matching-caption checks.

All 20 browser checks and six read-only readiness checks before and after passed, with no page errors. Stop released capture and every demo-owned process and port closed. ComfyUI and the existing model service were left in place.

The voice response reports 253 input / 19 output / 181 cached input tokens. Its current-session history is supplied by Korina; this does not establish durable memory, tools or future cache savings. There were no cloud model calls in this recording.

Qwen uses Vulkan and Kokoro uses ROCm. The local Kokoro runtime uses native ATen GPU LSTM because the installed MIOpen acceleration path lacks a required header. Whistle's official engine uses CPU. Physical microphone/headset, echo and human interruption remain separate checks.
