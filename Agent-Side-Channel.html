Agent Side Channel

Korina Converse is designed as a reusable voice/design chat channel for multiple agents. The side channel exposes a clean protocol so Korina Agent, Hermes Agent, OpenClaw, or any OpenAI-compatible agent can attach without being coupled to Korina's internal service code.

Protocol Overview

DirectionEndpointPayload
Converse to AgentPOST /api/agent/transcriptTranscript delta, reason, turn count, delivery mode
Agent to ConverseGET /api/agent/eventsEvent stream: state_report, permission_request, agent_status, agent_error
Converse to AgentPOST /api/agent/permission-answerUser answer to a permission request
EitherPOST /api/agent/resetClear agent state and events

Event Priority Levels

  • normal — Stored as hidden next-reply injection in Converse history.
  • important — Spoken by Converse as a voice interrupt.
  • critical — Spoken immediately; bypasses cooldown. Permission requests are always critical.
